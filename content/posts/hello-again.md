这是第三次开博客了。前两次都死在同一个地方：写到第五篇的时候，开始觉得"这篇不够有深度，发出去丢人"，然后就不发了，然后就荒了。

所以这次先立规矩，写在最前面提醒自己。

## 规矩一：只记亲手验证过的东西

不写"据说"、"应该是"。要么我跑通过，要么我踩过坑，要么我读过源码确认过。二手知识不记——网上到处都是，不需要我抄一遍。

这条其实卡掉了很多想写的东西，但留下来的都值钱。

## 规矩二：写完就发，不攒

单篇可以只有 300 字。哪怕只是"今天发现 `vite` 插件的 `resolveId` 有个坑，记一下"，也发。深度是攒出来的，不是憋出来的——同一个主题写够五条短笔记，自然能合并成一篇长文。

## 为什么是 React

简历上 React 那一栏一直写的是"熟练运用"，但说实话，过去七年真正用的都是 Vue。只有一个 Yapi 改造的项目摸过 React 生态。

这不太诚实。

所以这个站点用 Next.js 写。不是为了追新，是因为**想补的短板只能靠真做项目补，看文档补不上**。写够三十篇，那一栏才敢改成"熟练"。

## 技术选型就三个原则

1. 能静态部署就不上服务器
2. 能不装依赖就不装
3. 能不用 Web Font 就不用（中文动辄几 MB，是极简站最大的敌人）

最终：Next.js App Router + 手写 CSS，Markdown 走 unified 管线，代码高亮用 Shiki。运行时依赖只有 React 本身。
